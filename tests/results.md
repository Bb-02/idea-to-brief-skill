# 验证记录

## 0.2.1 自动选择边界模拟

日期：2026-10-13。本轮仅补充发现阶段测试，未修改技能描述、正文或版本。

- 先确定 [场景 N](cases.md) 的 9 条输入及交付意图预期，再将不含预期的输入交给两个独立子 Agent。它们不继承项目对话，不读取正文、验收资料或其他结果，只返回是否选择加载及简短理由。
- 一组收到完整 description（528 字符），另一组收到其前 250 字符。每组在一次批量判断中处理 9 条输入，要求将其视为独立新对话；各输入并非真实独立客户端会话。
- 截短条件参考 [ZCode 技能文档](https://zcode.z.ai/cn/docs/skill) 对描述摘要长度的说明，仅用作压力模拟，不表示已经捕获该客户端实际注入的文本。
- 两组沿用当前会话可用模型，各运行一次，未提供宿主完整指令或其他竞争技能，也未测试 Qwen、DS 或 ZCode 的真实技能工具。

| 输入 | 完整描述的声明选择 | 前 250 字符的声明选择 | 对照预期 |
| --- | --- | --- | --- |
| T1 简单解释 | 不加载 | 不加载 | 符合普通问答边界 |
| T2 好奇加未来可能应用 | 不加载 | 不加载 | 属于允许的解释，不能证明所有模型都会如此 |
| T3 不知道如何组织调查 | 加载 | 加载 | 符合任务整理意图 |
| T4 明确要求研究任务 | 加载 | 加载 | 符合任务说明交付 |
| T5 立即调查并给结果 | 不加载 | 不加载 | 保留研究执行流程 |
| T6 泛称“研究一下” | 不加载 | 不加载 | 可解释为直接研究，不强求调用 |
| T7 共享借物柜的调查思路 | 加载 | 加载 | 另一领域的任务整理需求被识别 |
| T8 日常事务安排 | 不加载 | 不加载 | 未将普通计划扩大为研究 |
| T9 点名技能 | 加载 | 加载 | 显式指定对照，不算自动选择证据 |

本次两组声明选择一致，未观察到截短条件下的选择差异；不能由此推断摘要长度没有影响，或两组判断具有统计独立性。没有发生实际技能加载、任务生成或下游执行，也不据此报告自动触发率。原始设置与结果留在忽略目录，本表仅记录模拟观察。客户端实测仍按场景 N 的步骤单独进行。

文档变更的相对链接、内容与空白检查通过；暂存区仅包含 README、行为场景和验证记录三个预期文件，不包含原始模拟输出或缓存。

## 0.2.1 中文表达与深度校准

日期：2026-10-13。此轮针对探索兴趣被升级为正式项目、额外假设和固定英文标签进行小范围修订，保留自包含任务说明作为主交付。

### 设置与范围

- 独立子 Agent 只读取修改后的 Skill、按需引用和单个自然语言请求，不继承项目对话，也不读取 README、示例、验收条件或其他试跑输出。
- 博物馆案例使用用户反馈的问题作同题回归；另用 [场景 M](cases.md) 的线上讲座问题检查迁移，用场景 C 检查明确的深度研究不会被一律简化。
- 使用本会话可用的模型环境，每个输入各生成一次。没有重跑用户的 Qwen 环境，也没有做跨模型或启用／停用 Skill 的对照。
- 工具记录为本地文件读取、响应保存与文件核验；没有执行下游联网研究。原始输出仅保留在被忽略的本地验证目录，不发布来源对话或调试日志。

### 生成行为观察

| 案例 | 实际观察 | 结论与限制 |
| --- | --- | --- |
| 展览体验同题回归 | 直接给可交接的中文任务，优先解释体验，未来展览保持为可能用途；原因作为待检验线索，未编造预算、参观经历或认知偏差诊断，未指定报告阅读时长 | 本次未复现反馈中的加重范围与假设问题；这不是对原模型的修复验证 |
| M 线上讲座探索 | 调查当前体验，比较专业性、投入与学习结果；未来分享只作为条件性应用，不扩展为课程设计或教学法综述。给出来源、观察线索和停止扩展的条件 | 本次达到场景条件，支持规则可用于另一话题；单次输出不足以证明稳定泛化 |
| C 游戏引擎深度研究 | 保留独立问题、真实团队和 AI 使用核实、失败案例、成本情境、原型验证建议和收敛标准，没有固定并发或预选唯一赢家 | 本次保留了明确要求的深度，没有被新规则压成浅层清单 |

三份输出均直接交付正文，没有机械插入 Brief / Prompt 标签或以执行邀约收尾；必要的技术名称仍保留。判断基于范围、假设与交付内容的人工检查，不以关键词命中作为通过标准。

## 0.2.0 历史记录

日期：2026-10-13。对象：以独立 Brief / Prompt 为主交付的本地修订版。

### 实际设置

- 环境为 Windows PowerShell，Python 3.12.10，Skills CLI 1.7.2。
- A、B、C 及前提检查变体由独立子 Agent 显式读取 Skill 和按需引用后生成，未继承项目对话，也未读取 README、手写示例、验收标准或其他试跑输出。模型沿用当前会话配置；没有进行跨模型比较。
