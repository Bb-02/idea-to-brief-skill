# 验证记录

## 0.3.0 任务设计与直接研究

日期：2026-10-13。本轮新增直接研究模式，保留独立任务说明交付。描述、正文、参考文件、界面简述、README、示例与贡献约束已同步；以下旧版记录仅对应各自版本。

### 实际设置

- 先在 [行为场景](cases.md) 中定义 O 的同题对照、P 的材料比较与多轮切换、Q 的能力不足和 R 的简单问答边界，再进行试跑。另回归 C 的深度任务设计。
- 每个初始行为场景使用不继承项目对话的独立子 Agent，只读取技能、按需引用、请求和必要材料；不给预期答案，不读取 README、测试条件或其他输出。P 的后续请求沿用其真实生成对话。
- 使用本会话可用模型，每个输入一次；不是 Qwen、DS 或 ZCode 测试。所有试跑禁止继续委派及外部写入，保存响应属于测试记录，不是用户交付要求。
- O2 允许真实只读联网研究；P 只使用明确标注为虚构的原始记录；Q 通过测试指令禁止网络访问来模拟缺少能力，并未物理移除宿主工具。
- 原始响应、选择输入与结果只保存在 Git 忽略目录。公开记录只写设置、观察和限制，不加入原始调试日志或私人对话。

### 加载后的行为与真实研究

## 0.2.1 自动选择边界模拟

- 先确定 [场景 N](cases.md) 的 9 条输入及交付意图预期，再将不含预期的输入交给两个独立子 Agent。它们不继承项目对话，不读取正文、验收资料或其他结果，只返回是否选择加载及简短理由。
- 一组收到完整 description（528 字符），另一组收到其前 250 字符。每组在一次批量判断中处理 9 条输入，要求将其视为独立新对话；各输入并非真实独立客户端会话。

- 两组沿用当前会话可用模型，各运行一次，未提供宿主完整指令或其他竞争技能，也未测试 Qwen、DS 或 ZCode 的真实技能工具。
